# 🌿 Portfólio Pessoal — Lucas Bispo da Cruz

Portfólio pessoal e acadêmico desenvolvido com **HTML, CSS e JavaScript**, com o objetivo de apresentar minha trajetória como estudante de Técnico Integrado em Informática no Instituto Federal de Mato Grosso do Sul (IFMS).

O site reúne meus projetos, conhecimentos técnicos, experiências acadêmicas e formas de contato, funcionando como um complemento ao meu currículo.

## 🎯 Objetivo

Apresentar minha evolução na área da tecnologia, documentar projetos desenvolvidos durante minha formação acadêmica e compartilhar experiências em feiras, eventos e atividades relacionadas à informática.

## ✨ Funcionalidades

- **Página inicial:** apresentação pessoal e acesso rápido às principais seções.
- **Sobre mim:** informações sobre minha formação e meus interesses.
- **Projetos:** apresentação de trabalhos desenvolvidos, com imagens, descrições e links para os repositórios.
- **Trajetória acadêmica:** registro de experiências e participações em eventos, como a FECINOVA.
- **Habilidades:** tecnologias e ferramentas estudadas durante minha formação.
- **Contato:** acesso ao e-mail, GitHub e LinkedIn.
- **Menu responsivo:** navegação adaptada para dispositivos móveis.
- **Alternância de tema:** opção entre tema escuro e claro.

## 🛠️ Tecnologias utilizadas

- HTML5 — estruturação das páginas.
- CSS3 — estilização, layout responsivo e temas visuais.
- JavaScript — interatividade, menu de navegação e alternância de tema.
- Git e GitHub — versionamento e disponibilização do código.

## 🚀 Como executar o projeto

1. Clone o repositório:

   ```bash
   git clone https://github.com/ZePingusso/SEU-REPOSITORIO.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd SEU-REPOSITORIO
   ```

3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor para executar a versão estática do portfólio.
